# متن کوتاه ارائه دانشگاهی

Dibz یک بازارچه برای نجات غذای سالمِ فروش‌نرفته است. کسب‌وکارهایی مثل کافه، رستوران، نانوایی، میوه‌فروشی و سوپرمارکت، موجودی اضافه همان روز یا کالاهای نزدیک پایان مهلت فروش را با تخفیف عرضه می‌کنند.

چون فروشگاه از قبل دقیقاً نمی‌داند چه چیزهایی فروش نمی‌رود، بخش اصلی محصول Surprise Box است. کاربر بسته را با قیمت کمتر رزرو می‌کند و در بازه مشخص حضوری تحویل می‌گیرد.

این نسخه، یک PWA قابل نصب و موبایل‌محور است که مسیر کشف بسته، مشاهده جزئیات، رزرو و دریافت کد را شبیه‌سازی می‌کند. برای نسخه واقعی، پنل فروشگاه، موجودی اتمیک، پرداخت، احراز هویت و گزارش کاهش دورریز اضافه می‌شود.
