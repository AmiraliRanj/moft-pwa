# سیستم طراحی مفت

## شخصیت بصری

آرام، تمیز، خوش‌خوراک و کمی بازیگوش. رابط باید حس محصول باکیفیت بدهد، اما لوکس و دور از دسترس نباشد.

## رنگ‌ها

- `--ink`: متن اصلی نزدیک به مشکی
- `--muted`: متن ثانویه خاکستری
- `--surface`: سفید گرم
- `--canvas`: کرم بسیار روشن
- `--brand`: سبز پسته‌ای تیره
- `--brand-soft`: سبز روشن
- `--accent`: مرجانی برای هشدار کمبود موجودی
- `--success`: سبز موفقیت

## تایپوگرافی

از stack سیستم استفاده شود تا بارگذاری سریع و حس native حفظ شود:

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Tahoma, Arial, sans-serif;
```

برای نسخه نهایی می‌توان فونت فارسی دارای مجوز را به‌صورت محلی اضافه کرد، اما فایل فونت نباید بدون مجوز داخل ریپو قرار گیرد.

## هندسه

- شعاع کارت بزرگ: 28px
- شعاع کنترل: 16px تا 20px
- دکمه اصلی: ارتفاع حداقل 52px
- فضای صفحه موبایل: 18px تا 22px
- Bottom Sheet: گوشه بالا 32px

## عمق

- Border نیمه‌شفاف
- سایه نرم و کوتاه
- Backdrop blur فقط برای Header، Bottom Nav و Sheet
- از چندین سایه هم‌زمان پرهیز شود

## Motion

- مدت معمول: 180 تا 280ms
- ورود: ease-out
- خروج: کوتاه‌تر از ورود
- Scale فشردن دکمه حداکثر 0.98
- در `prefers-reduced-motion` انیمیشن حذف یا بسیار محدود شود

## اصل استقلال برند

Apple-inspired به معنی استفاده از اصول کیفیت و سادگی است، نه کپی صفحه، آیکن، نام‌گذاری یا assetهای اپل.
