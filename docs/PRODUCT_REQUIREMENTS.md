# نیازمندی‌های محصول

## محدوده نسخه ارائه دانشگاهی

### صفحه خانه

- نمایش موقعیت نمونه
- جست‌وجوی نمایشی
- دسته‌بندی کسب‌وکارها
- کارت بسته‌های نزدیک
- تعداد باقی‌مانده و بازه تحویل
- قیمت مرجع و قیمت رزرو

### جزئیات بسته

- نام فروشگاه و نوع کسب‌وکار
- امتیاز نمونه
- توضیح مفهوم Surprise Box
- نمونه آلرژن‌ها با هشدار اینکه ترکیب دقیق متغیر است
- بازه Pickup
- تعداد باقی‌مانده
- دکمه رزرو

### رزرو نمایشی

- انتخاب تعداد محدود
- تأیید رزرو بدون پرداخت واقعی
- تولید کد تحویل نمایشی
- ذخیره وضعیت در Local Storage

### رزروهای من

- رزرو فعال
- کد تحویل
- زمان و آدرس Pickup
- وضعیت «آماده دریافت» یا «تحویل‌شده» به‌صورت Mock

### پروفایل

- تأثیر نمایشی: تعداد وعده نجات‌یافته و CO2 تخمینی
- تنظیم آلرژی نمایشی
- لینک «همکاری با مفت»

## خارج از محدوده Preview

- پرداخت واقعی
- احراز هویت واقعی
- موجودی هم‌زمان چند فروشگاه
- پنل شریک تجاری کامل
- نقشه و مکان‌یابی زنده
- اعلان Push واقعی
- قوانین بازپرداخت و پشتیبانی واقعی

## نسخه واقعی پیشنهادی

1. احراز هویت OTP
2. پنل شریک تجاری
3. دیتابیس PostgreSQL
4. رزرو اتمیک موجودی
5. درگاه پرداخت
6. اعلان آماده‌سازی و یادآوری Pickup
7. گزارش دورریز جلوگیری‌شده
8. مدیریت شکایت، لغو و No-show

## قواعد ایمنی محصول

- فقط غذای سالم و قابل مصرف عرضه شود.
- کالای تاریخ‌گذشته قابل فروش نیست.
- برای آلرژن‌ها، فروشگاه باید دسته‌های احتمالی را مشخص کند.
- Surprise Box به معنی نامشخص بودن ترکیب است، نه نامشخص بودن ایمنی.
- زمان نگهداری و Pickup باید توسط فروشگاه رعایت شود.
