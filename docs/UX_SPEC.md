# UX Specification

## مسیر اصلی کاربر

1. کاربر صفحه خانه را باز می‌کند.
2. دسته یا کارت نزدیک را انتخاب می‌کند.
3. Bottom Sheet جزئیات باز می‌شود.
4. کاربر مفهوم Surprise Box و زمان Pickup را می‌بیند.
5. دکمه «رزرو این بسته» را می‌زند.
6. پیام موفقیت و کد تحویل نمایش داده می‌شود.
7. رزرو در تب «رزروها» قابل مشاهده است.

## ناوبری

Bottom navigation با چهار مقصد:

- خانه
- کشف
- رزروها
- پروفایل

در دسکتاپ، همین ساختار داخل یک قاب مرکزی با حداکثر عرض کنترل‌شده باقی بماند تا هویت موبایل‌محور حفظ شود.

## رفتارهای نمایشی

- فیلتر دسته‌ها واقعاً کارت‌ها را فیلتر کند.
- Search بر نام فروشگاه و نوع دسته اثر بگذارد.
- رزرو با Local Storage پایدار بماند.
- شمارنده موجودی پس از رزرو کاهش یابد.
- Install PWA فقط زمانی نمایش داده شود که مرورگر رویداد نصب را ارائه کند.

## حالت‌ها

- Empty state برای فیلتر بدون نتیجه
- Offline page
- Toast موفقیت رزرو
- Disabled state زمانی که موجودی صفر است
- Skeleton ضروری نیست مگر داده واقعی اضافه شود

## متن‌های کلیدی

- تیتر: «خوب‌ها رو قبل از دورریز بردار»
- برچسب: «Surprise Box»
- CTA: «رزرو این بسته»
- اعتمادسازی: «ترکیب بسته متغیر است؛ ایمنی و شرایط نگهداری باید توسط فروشگاه رعایت شود.»
