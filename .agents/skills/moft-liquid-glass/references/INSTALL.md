# Install

Copy the `moft-liquid-glass` folder into your repository:

```text
<repo>/.codex/skills/moft-liquid-glass/
```

The required entry file is:

```text
<repo>/.codex/skills/moft-liquid-glass/SKILL.md
```

Then restart/reload Codex so it discovers the skill.

You can invoke it explicitly with wording such as:

```text
Use the moft-liquid-glass skill to rebuild the Business mobile bottom navigation with real optical Liquid Glass, preserving iPhone performance and accessibility.
```

Or:

```text
Use moft-liquid-glass to audit the current frontend and propose a staged Liquid Glass migration. Do not change code yet.
```
