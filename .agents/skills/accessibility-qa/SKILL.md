# Accessibility QA

Review the changed flow, not only individual components.

- Check headings and landmarks.
- Check every button name and icon label.
- Check keyboard dismissal of dialogs and sheets.
- Check visible focus without relying on color alone.
- Check reduced motion.
- Check that status messages are announced where practical.
- Check fixed navigation does not cover content.
- Check Persian RTL order and mixed-number readability.

Fix issues directly when the request permits, then run project checks.
