EDITIONS

Edition Lab

Editions are a separate axis from tiers: the same achievement, the same illustration, a different print treatment. The renderer recolors the whole layer stack from the edition palette and adds a single overlay layer (star field / newspaper masthead / bazaar tiles). Intentional, not procedurally random.
