# استارتر PWA پروژه «مفت»

این پوشه یک نمونه قابل اجرا و یک بسته راهبری برای Codex است تا نسخه دانشگاهی «مفت» را توسعه دهد.

## داخل بسته چیست؟

- یک PWA فارسی و RTL با Next.js App Router و داده‌های نمایشی
- رابط Apple-inspired با هویت مستقل «مفت»
- `AGENTS.md` برای قوانین دائمی پروژه
- Skillهای پروژه در `.agents/skills/`
- Hookهای Codex در `.codex/hooks.json`
- مستند محصول، UX، مدل داده و نقشه راه
- پرامپت‌های مرحله‌ای برای ساخت، پولیش و دیپلوی
- اسکریپت اعتبارسنجی ساختار پروژه

## اجرای سریع

نیازمندی: Node.js 20.9 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:3000
```

## شروع با Codex

1. پوشه را در Codex باز کنید.
2. فایل `AGENTS.md` را نگه دارید و حذف نکنید.
3. در Codex دستور `/hooks` را باز کنید و Hookهای همین ریپو را پس از بررسی Trust کنید.
4. فایل `prompts/01_BOOTSTRAP_CODEX.md` را به Codex بدهید.
5. برای اجرای مستقیم Skill می‌توانید از `$moft-product-builder` استفاده کنید.

## دیپلوی روی Vercel

روش Git:

1. پروژه را در GitHub قرار دهید.
2. در Vercel گزینه Add New Project را بزنید.
3. ریپو را Import کنید.
4. Framework Preset باید Next.js باشد.
5. Deploy را بزنید.

روش CLI:

```bash
npm i -g vercel
vercel
vercel --prod
```

## محدودیت نسخه نمایشی

این نسخه عمداً با داده Mock ساخته شده و پرداخت، احراز هویت و دیتابیس واقعی ندارد. برای ارائه دانشگاهی، مسیرهای اصلی کاربر شبیه‌سازی شده‌اند:

- دیدن بسته‌های نزدیک
- فیلتر فروشگاه‌ها
- مشاهده جزئیات Surprise Box
- رزرو نمایشی
- نمایش رزروها و پروفایل
- نصب PWA

نقشه راه نسخه واقعی در `docs/PRODUCT_REQUIREMENTS.md` و `docs/DATA_MODEL.md` آمده است.
