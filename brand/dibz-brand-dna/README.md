# ارائهٔ هویت برند دیبز

این پوشه نسخهٔ مستقل، واکنش‌گرا و فارسی ارائهٔ هویت برند دیبز را در خود دارد.

## پیش‌نمایش

فایل `index.html` را مستقیماً در مرورگر باز کنید یا ریشهٔ مخزن را با یک سرور استاتیک محلی اجرا کرده و به مسیر زیر بروید:

`/brand/dibz-brand-dna/`

ارائه از اسکرول، کنترل‌های روی صفحه و کلیدهای `←`، `→`، `↑`، `↓`، `Page Up`، `Page Down`، `Home`، `End` و `Space` پشتیبانی می‌کند.

## خروجی PDF

1. فایل `index.html` را در Chrome، Edge یا Safari باز کنید.
2. از بخش **Print** گزینهٔ **Save as PDF** را انتخاب کنید.
3. گزینهٔ **Background graphics** را فعال کنید.
4. حاشیه را روی **None** و مقیاس را روی **100%** بگذارید.

## دارایی‌های محلی

ارائه از شخصیت موجود دیبز، آیکن iOS، مجموعهٔ Liquid Glass، فایل SVG دستکش و بستهٔ موجود Vazirmatn استفاده می‌کند. هیچ وابستگی یا درخواست خارجی تازه‌ای لازم نیست.
