# Dibz Brand DNA presentation

This directory contains the standalone, responsive Dibz Brand DNA HTML presentation.

## Preview

Open `index.html` directly in a modern browser, or serve the repository root with any existing local static server and navigate to:

`/brand/dibz-brand-dna/`

The deck supports scrolling, the on-screen arrow controls, and the keyboard keys `←`, `→`, `↑`, `↓`, `Page Up`, `Page Down`, `Home`, `End`, and `Space`.

## Export to PDF

1. Open `index.html` in Chrome, Edge, or Safari.
2. Choose **Print** and select **Save as PDF**.
3. Enable **Background graphics**.
4. Use the default presentation page size generated by the print stylesheet, with margins set to **None** and scale set to **100%**.

## Local assets

The presentation references the existing Dibz mascot, iOS icons, Liquid Glass icon set, and the repository's existing Vazirmatn package. No external requests or added dependencies are required.
